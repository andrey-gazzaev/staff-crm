# Смена

Небольшая CRM на Next.js: прогресс сотрудников, их задачи, таблицы и графики. Данные демо, без сервера.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- `/` — обзор: цифры, график недель, статусы, очередь
- `/employees` — прогресс по людям и таблица
- `/tasks` — статусы и таблица задач
